# INV 技术方案

INV 管销项开票、进项查验抵扣和税务属期。OMS、BMS、SRM 经开放接口推单据。IR 拉发票快照，并下发查验、提交和审核。

## 1. 运行位置

| 场景 | 后端 |
| --- | --- |
| 单机 | `8080` |
| 与控制塔同机 | `8089` |

`/api/open/**` 用 `X-Api-Key`，不走登录令牌。控制塔种子键 `inv-open-key`。

## 2. 主链路

```text
销项：开票申请 → 审核 → 取号开具 → 交付 → 作废/红冲
进项：录入 → 查重 → 查验 → 勾选抵扣 → 入账
```

上游推送仍走原有 `/api/open` 销项申请和进项票口，与控制塔指令分开。

## 3. 控制塔读

`GET /api/open/ir/snapshots`：

| dataType | 业务键 | 状态 |
| --- | --- | --- |
| `INVOICE_REQUEST` | 申请号 | 申请状态 |
| `SALES_INVOICE` | 发票号码 | 发票状态 |
| `INPUT_INVOICE` | 进项发票号码 | 查验状态 |

## 4. 控制塔写

必须带 API Key。控制塔登录模式不调用这些指令。

| 指令 | 专用口 | 作用 |
| --- | --- | --- |
| `INV_VERIFY_INPUT` | `POST /api/open/ir/verify-input` | 按发票号查验进项 |
| `INV_SUBMIT_REQUEST` | `/submit-request` | 按申请号把草稿提交 |
| `INV_APPROVE_REQUEST` | `/approve-request` | 按申请号审核 |

统一口是 `POST /api/open/ir/actions`。专用口把 `invoiceNo` 或 `requestNo` 补成 `targetKey`。非空幂等键去重。

## 5. 边界

审核通过不会自动开票。属期关账后，作废和勾选仍按本系统税务规则拒绝。控制塔不生成税控报文。

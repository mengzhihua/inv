# INV 亮点

INV 覆盖销项开票、进项抵扣和税务属期。订单、结算、采购把单据推过来，税务规则留在本系统。

1. **销项从申请走到红冲。** 税额按行计算并做容差校验，专票校验必填项，超限额自动拆分，多申请可以合并，开具后能作废或红冲。
2. **进项不是只存一张发票影像。** 录入后查重、查验、勾选抵扣、三单匹配、入账，查验状态能单独给控制塔看。
3. **属期关账会拦住不该做的动作。** 关账后，销项作废和进项勾选不再放行。申报预填按税率给出销项、进项和应纳税额。
4. **费用发票先过合规再报销。** 重复、抬头不符、过期、查验失败和超额会变成风险项，没有风险才算可报销。
5. **控制塔推动查验、提交、审核和开具。** 必须带开放密钥。审核通过不会自动开票，开具是下一步单独指令。查验结果分成通过、抬头不符和校验码失败。
